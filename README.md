**Eğitim projesi.** CSS veya JavaScript kullanılmamıştır. Form yalnızca HTML öğelerini örnekler; GitHub Pages üzerinde gönderilen mesajlar kaydedilmez.

## GitHub Pages

Bu klasördeki dosyaları `aesthetic-photo-archive` adlı **yeni ve herkese açık** bir GitHub deposunun *kök dizinine* yerleştirin. `main` dalından yayımlamayı etkinleştirmek için deponun **Settings > Pages > Build and deployment > Source > GitHub Actions** seçeneğini kullanın. Depoda bulunan `.github/workflows/pages.yml` dosyası yayını otomatik gerçekleştirir.

Bu dosyaları `yildiz-lab` deposuna **eklemeyin**. Canlı sitenin gerçek adresi GitHub Pages başarılı dağıtımı sonrasında Settings > Pages bölümünde gösterilir.

Üniversite teslim raporuna **yalnızca doğrulanmış canlı adresi ve canlı sayfanın ekran görüntüsünü** ekleyin.
